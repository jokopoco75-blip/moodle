# Курсор — учебная платформа

Учебная платформа для небольших образовательных организаций: преподаватели превращают материалы на казахском языке в короткие конспекты и интерактивные тесты с помощью ИИ. Каждый ИИ-материал остаётся черновиком до проверки преподавателем. Интерфейс собран в одном `index.html`, сервер и SQLite обеспечивают аккаунты и совместную работу.

## Запуск в Windows

Нужен Node.js версии 22.13 или новее. Установите Node.js, затем в PowerShell перейдите в папку проекта и выполните:

```powershell
Copy-Item .env.example .env
node --env-file-if-exists=.env server.mjs
```

Откройте `http://localhost:3000`. Не открывайте `index.html` двойным щелчком: вход, база данных и серверная проверка прав работают через Node-сервер.

При установленном npm можно запустить также `npm start`. Сторонние npm-пакеты устанавливать не нужно: сервер использует встроенные модули Node.js, включая SQLite.

## Демо-аккаунты

При первом запуске в режиме разработки создаются четыре аккаунта и два курса. У всех демо-аккаунтов пароль `demo1234`.

| Роль | Почта |
| --- | --- |
| Администратор | `admin@demo.ru` |
| Преподаватель | `teacher@demo.ru` |
| Студент | `student1@demo.ru` |
| Студент | `student2@demo.ru` |

Данные сохраняются в `data/moodle.sqlite`, а загруженные вложения — отдельно в `data/uploads`; резервные копии следует включать для обеих частей. Для настоящей установки сначала задайте собственный `ADMIN_EMAIL` и сильный `ADMIN_PASSWORD`, затем включите `NODE_ENV=production`. В production демонстрационные пользователи не создаются; сервер не запустится с пустым паролем администратора при первой инициализации.

## Возможности

- Регистрация студентов, вход, выход, профиль и смена пароля.
- Роли администратора, преподавателя и студента с проверкой доступа на сервере.
- Курсы, разделы, материалы и запись на курс.
- Загрузка, просмотр PDF и скачивание PDF, TXT, MD, DOCX, ODT и PPTX (до 20 МБ на файл).
- Задания, отдельная страница задания, сдача ответа, оценка и отзыв преподавателя.
- Тесты с проверкой ответа на сервере и разбором результата.
- Прогресс по материалам связан с результатом обучения: студент проходит проверочный тест курса с результатом от 70% и объясняет тему своими словами. Результаты тестов формируют показатель освоения темы.
- ИИ-репетитор, конспект и создание теста по выбранному материалу, черновик обратной связи преподавателю.
- Экспорт и импорт резервной копии JSON администратором, экспорт журнала оценок в CSV.
- Русский, английский, корейский, польский и казахский интерфейсы; светлая и тёмная темы.

## Настройка ИИ

ИИ подключается по желанию. Создайте API-ключ у выбранного провайдера, сохраните его в `.env` в переменной `OPENAI_API_KEY` и перезапустите сервер. При необходимости укажите доступную вашей учётной записи модель в `OPENAI_MODEL`. Пример конфигурации использует OpenAI Responses API. Без ключа чат-репетитор даёт локальные подсказки; генерация конспектов, тестов и комментариев преподавателю требует настроенного ключа. ИИ-тесты для курса становятся доступны студентам после подтверждения преподавателем. Черновики хранят источник, модель, время генерации и версию. [Официальная документация OpenAI Responses API](https://developers.openai.com/api/docs/guides/text).

Ключ нельзя помещать в `index.html`. Для ИИ по материалу передаётся описание, а из файлов — текст TXT/MD. PDF и документы можно открыть или скачать в курсе; извлечение текста из PDF/DOCX в ИИ-контекст не включено.

## Резервные копии

Экспорт JSON включает учебные данные и вложения материалов, но не пароли и не хеши паролей. При импорте администраторских данных существующие аккаунты и их пароли сохраняются, а учебные записи заменяются содержимым копии. Это позволяет хранить резервный файл отдельно от учётных данных.

## Развёртывание в интернете

Для публичного сайта запустите Node-сервер на хостинге и поставьте перед ним HTTPS reverse proxy. Настройте постоянный каталог `DATA_DIR`, переменные окружения, доступ к резервному копированию SQLite и ограничение входящего трафика. Этот архив готов к запуску на сервере, но публичный домен и хостинг к нему не привязаны.
